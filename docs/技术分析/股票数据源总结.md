## 二、各数据源详述

---

### 1. yfinance

| 维度 | 说明 |
|------|------|
| **来源** | Yahoo Finance（非官方接口，通过爬虫解析网页/API） |
| **安装** | `pip install yfinance` |
| **费用** | 免费，无需注册或 API Key |
| **市场** | 全球多市场：美股、A 股（含沪深300成分股）、港股、日股等 |
| **数据类型** | 日线/分钟线历史行情、基本面指标、财务报表、分红/拆股、持仓信息 |
| **实时性** | 非实时，有 15 分钟以上延迟；分钟线数据也有限制 |
| **优点** | 使用简单（`yf.download(ticker)` 即用）、覆盖面广、免费无门槛 |
| **缺点** | 非官方接口，Yahoo 反爬策略随时可能变动导致不可用；A 股数据不如国内专有数据源完整；延迟大不适合盘中交易决策 |
| **适用场景** | 盘后分析、回测研究、全球市场概览、非实时的因子计算 |
| **不适用** | 盘中实时盯盘、依赖 Tick 级数据的策略、高频交易 |
