## 一、需求描述

### 1.1 背景

用户持有多只公募基金，通过支付宝等渠道买入。目前只能在晚间基金净值公布后查看当日收益，无法在盘中及时了解持仓基金的大致涨跌情况，导致操作决策滞后。

### 1.2 核心需求

1. **持仓管理**：建立数据库表，记录用户持有的基金信息（代码、名称、买入净值、份额、买入日期、行业板块等）。
2. **盘中净值估算**：每个交易日 **14:30**，根据基金重仓股的实时涨跌幅和持仓占比，估算当日基金净值变化。
3. **收益计算**：基于估算净值，计算每只基金的累计盈亏和当日盈亏。
4. **操作建议**：根据盈亏情况和当日涨跌，自动生成操作建议：继续持有 / 加仓 / 减仓 / 清仓。

### 1.4 使用场景

```
交易日 14:30 → 系统自动触发估算 → 
输出：每只基金估算涨跌幅 + 当日盈亏 + 累计盈亏 + 操作建议 →
用户根据建议决定是否操作
```

## 二、详细设计

### 2.1 核心思路

基金实时净值无法直接获取（公募基金每日公布一次净值，通常在晚间）。但可通过以下方式近似估算：

```
估算净值变化 ≈ Σ( 基金持仓股票权重 × 该股票当日实时涨跌幅 )
```

结合基金季报公布的**前十大重仓股及占净值比例**，以及股票的**日内实时价格变化**，在 14:30 得到基金的近似涨跌幅。

### 2.2 系统架构

```
┌──────────────────────────────────────────────────────┐
│                    外部定时调度器                       │
│               (每天 14:30 触发)                        │
└─────────────────────┬────────────────────────────────┘
                      │ XADD cron:jobs:nav_estimation
                      ▼
┌──────────────────────────────────────────────────────┐
│              nav_estimation_worker                    │
│  (新增 Redis Streams Consumer)                        │
├──────────────────────────────────────────────────────┤
│  1. 读取用户持仓表 (fund_user_holding)                  │
│  2. 读取每只基金的重仓股及权重 (fund_holding)           │
│  3. 获取重仓股日内实时涨跌幅 (腾讯行情)                 │
│  4. 加权计算基金估算净值涨跌幅                          │
│  5. 写入估算结果表 (fund_nav_estimation)                │
│  6. 计算用户收益摘要 (fund_user_pnl_summary)             │
│  7. 输出操作建议                                      │
└──────────────────────────────────────────────────────┘
```

### 2.3 数据库表设计

#### fund_user_holding（用户持仓表）

记录用户持有的基金及买入信息。

```sql
CREATE TABLE IF NOT EXISTS fund_user_holding (
    id              SERIAL PRIMARY KEY,
    fund_code       TEXT NOT NULL,              -- 基金代码
    fund_name       TEXT,                        -- 基金名称
    buy_net_value   REAL NOT NULL,              -- 买入净值
    shares          REAL NOT NULL,              -- 持有份额
    buy_date        TEXT NOT NULL,              -- 买入日期 YYYY-MM-DD
    holding_days    INTEGER DEFAULT 0,          -- 已持有天数
    industry_sector TEXT,                        -- 行业板块
    source          TEXT DEFAULT 'ali',          -- 购买渠道
    is_qdii         BOOLEAN DEFAULT FALSE,       -- 是否QDII
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);
```

#### fund_nav_estimation（盘中净值估算表）

记录每次 14:30 的估算快照，可追溯历史估算准确度。

```sql
CREATE TABLE IF NOT EXISTS fund_nav_estimation (
    id              SERIAL PRIMARY KEY,
    fund_code       TEXT NOT NULL,               -- 基金代码
    trade_date      TEXT NOT NULL,               -- 交易日期 YYYY-MM-DD
    estimate_time   TIMESTAMPTZ NOT NULL,        -- 估算时间
    last_nav        REAL,                        -- 上一交易日公布净值
    estimated_nav   REAL,                        -- 估算当前净值
    estimated_pct   REAL,                        -- 估算涨跌幅(%)
    coverage_pct    REAL,                        -- 重仓股覆盖比例(%)，反映估算可信度
    stock_detail    JSONB,                       -- 各重仓股涨跌明细
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(fund_code, trade_date, estimate_time)
);
```

#### fund_user_pnl_summary（用户收益汇总表）

每日收益快照 + 操作建议，可直接用于决策。

```sql
CREATE TABLE IF NOT EXISTS fund_user_pnl_summary (
    id              SERIAL PRIMARY KEY,
    trade_date      TEXT NOT NULL,               -- 交易日期
    fund_code       TEXT NOT NULL,               -- 基金代码
    buy_net_value   REAL NOT NULL,              -- 买入净值
    current_nav     REAL,                        -- 当前净值（盘中估算或最新公布）
    shares          REAL NOT NULL,              -- 持有份额
    cost            REAL NOT NULL,              -- 成本 = buy_net_value × shares
    market_value    REAL,                        -- 市值 = current_nav × shares
    total_pnl       REAL,                        -- 累计盈亏（金额）
    total_pnl_pct   REAL,                        -- 累计盈亏（%）
    daily_pnl       REAL,                        -- 当日盈亏（金额）
    daily_pnl_pct   REAL,                        -- 当日盈亏（%）
    suggestion      TEXT,                        -- 操作建议: HOLD / BUY / REDUCE / CLEAR
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(trade_date, fund_code)
);
```

### 2.4 核心计算逻辑

#### 基金净值估算

```python
def estimate_fund_nav(fund_code: str):
    """
    估算公式:
      estimated_pct = Σ(weight_i × stock_pct_change_i)
      estimated_nav = last_nav × (1 + estimated_pct / 100)

    其中:
      weight_i      = 重仓股 i 占基金净值比例 (nav_pct / 100)
      stock_pct_change_i = 重仓股 i 当日实时涨跌幅 (%)
      last_nav      = 上一交易日基金公布净值
      coverage_pct  = Σ(nav_pct)，通常 30%-60%，用于表示估算可信度
    """
    # 1. 从 fund_holding 读取该基金最新的重仓股及 nav_pct
    # 2. 从实时行情接口获取每只重仓股的当日涨跌幅
    # 3. 加权求和得到估算涨跌幅
    # 4. 基于上日净值计算估算当前净值
```

#### QDII 基金特殊处理

QDII 基金投资海外市场，A股交易时段内海外市场通常休市。处理策略：

- 使用**标的指数期货**或**对应 ETF** 的日内走势作为代理变量
- 例如：港股 QDII → 恒生指数期货，美股 QDII → 纳斯达克 100 期货
- 若无期货数据，标记为"无法日内估算"，使用前日净值。`coverage_pct = 0`

#### 操作建议规则（初版）

| 条件 | 建议 | 含义 |
|------|------|------|
| 累计盈利 > +15% 且 当日跌幅 > -2% | `REDUCE` | 减仓止盈 |
| 累计盈利 > +30% 且 当日跌幅 > -1.5% | `CLEAR` | 清仓止盈 |
| 累计亏损 < -10% | `CLEAR` | 止损清仓 |
| 累计亏损 < -5% 且 当日跌幅 > -2% | `REDUCE` | 减仓止损 |
| 当日涨幅 > 2% 且 累计亏损中 | `BUY` | 加仓摊薄 |
| 其他 | `HOLD` | 持有观望 |

> 阈值可通过 `config/nav_estimation.yaml` 配置。

### 2.8 局限性与注意事项

1. **估算精度有限**：基金季报只公布前十大重仓股，通常覆盖 30%-60% 净值，剩余部分无法跟踪。估算涨跌幅会与晚间公布的真实净值存在偏差。
2. **季报滞后**：季报截止日后约 15-20 个交易日才公布，基金经理可能已调仓。估算偏差随时间推移逐渐增大。
3. **QDII 估算困难**：海外市场与 A 股交易时间不重叠，日内无法直接获取持仓股票行情，只能通过期货/ETF 代理估算。
4. **债券型/货币型基金**：重仓股逻辑不适用，需独立处理。
5. **费率影响**：估算未扣除申购/赎回费，实际操作时需考虑。
